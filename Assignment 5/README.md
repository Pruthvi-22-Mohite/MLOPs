# Iris Classification REST API

## Objective

This project implements a REST API using FastAPI to serve predictions
from a trained Iris flower classification model.

## Technologies

- Python
- FastAPI
- Scikit-learn
- NumPy
- Joblib
- Pydantic
- Pytest
