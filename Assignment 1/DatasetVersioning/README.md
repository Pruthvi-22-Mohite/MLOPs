# DatasetVersioning

This is the DVC project for Assignment 1. The student dataset is kept in `data/`
and its DVC pointer is `data/student.csv.dvc`. DVC configuration in `.dvc/`
points to the repository-local remote at `../../dvc-storage`.

## Useful commands

```bash
dvc status
dvc pull
dvc push
```

Run these commands from this directory. The nested `.dvc` cache and temporary
directories are generated by DVC and should not be edited manually.
